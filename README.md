# MOVOKA

연극·뮤지컬·콘서트·클래식 등 공연 정보를 한곳에서 찾고, 공연장과 공식 정보를 확인할 수 있는 서비스입니다.

## 데이터 원칙

- 공연 데이터는 **공연예술통합전산망(KOPIS) Open API**를 우선 사용합니다.
- KOPIS API 키는 `KOPIS_API_KEY` Cloudflare 환경변수로만 관리합니다.
- 브라우저에 API 키를 노출하지 않습니다.
- 예매 링크는 향후 공식 제공 정보가 확인되는 경우에만 연결합니다.
- 비공식 공연정보 API, 무단 스크래핑, 임의로 생성한 예매 URL은 사용하지 않습니다.
- KOPIS 공연정보는 최초 결제 다음날 전송 및 검증 후 DB에 반영되고, 매일 10시와 15시에 업데이트되므로 '실시간 잔여좌석' 서비스로 표시하지 않습니다.

## 현재 구현

- 반응형 공연정보 메인 화면
- 연극/뮤지컬/클래식/대중음악/무용/아동 카테고리
- 공연명·공연장 검색
- 다크모드
- KOPIS 서버 프록시
- API 키 브라우저 비노출 구조

## 배포 환경

Cloudflare Pages/Workers Functions 기준으로 `/api/performances`를 사용합니다.
